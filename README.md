# Student Record Management System

A simple command-line Python project to manage student records using CRUD operations. Data is saved in a JSON file, so it stays after the program closes.

## Features
- Add a new student
- View all students
- Update a student's details
- Delete a student
- Data stored in `students.json`
- Error handling for wrong input

## Technologies Used
- Python 3
- JSON (file handling)

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the folder in a terminal and run:
   python main.py
4. Choose an option from the menu (1 to 5).

## Menu
1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Exit
